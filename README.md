## Description
This Julia package provides analysis tools to analyze [JAMS simulations](https://github.com/sanderkammeraat/JAMS.jl).


## Installation
In a Julia script or from the REPL run
```
using Pkg
Pkg.add(url="https://github.com/sanderkammeraat/JARS.jl")
```

You can then use it in a Julia script or REPL by importing the package:

```using JARS```
